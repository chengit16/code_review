## 核对口径

- Agent 覆盖按实际核对的页数及差异记录计量。OCR 覆盖按初审选择的文件计量。即使页数完整，跨页、跨文件或差异外代码所需的证据仍可能缺失。
- 同位置建议可用于定位，匹配需确认是否为同一根因。根因一致时，两边的发现分别保存裁定，并用同一个匹配记录关联。
- 只把手工核实的缺陷记为命中或漏报。双路零发现的样本仍需人工检查差异。仅出现在未变化代码中的问题需核对是否由本次改动引入或变得可达。
- 用量为两路各自已返回的输入和输出 Token 之和。耗时为对应尝试的开始到结束，含本地证据准备，不含排队。Agent 模型回执未提供可核对金额。两路在上下文和历史模型条件上可能不同，耗时与 Token 仅描述这些已记录的运行。
