# Ant Design 首批接入与运行监控改造

日期：2026-11-08。关联 PI-20261107-007、PI-20261107-010；其余页面按 PI-20261107-011 规划继续。代码接入和本地验收不代表业务实例已经发布。

## 本批交付

- 锁定 `antd@6.7.0`，应用级中文语言、灰白蓝主题与上下文弹窗由 `frontend/src/app/DesignProvider.tsx` 管理。不引入 ProComponents、Ant Design Pro 或图表库。
- AGENTS.md 与前端规范规定新增/重设计的通用控件统一 Ant Design；业务组件、语义 HTML 和浏览器原生关闭确认保留，复杂状态不同时机械迁入 Form。
- 运行监控拆成“运行与并发 / 性能分析 / 告警与通知 / 维护与审计”，URL 标签、刷新和返回保留定位。默认运行页将并发与槽前置，窄屏先显示并发面板。
- 初审排队/运行读 `execution_jobs`，不再使用有效结论状态冒充执行数；旧 API 缺失显示未知。历史失败与运维风险分开展示，不解析告警文字猜恢复动作。
- 并发保留 1～10 整数校验、冻结版本、409 保留草稿且不重放；并列展示已保存、已应用、执行中和排空，版本未对齐提示等待后续确认。
- 性能采用紧凑分组表、URL 本地筛选、分页和行详情；不合成总体分位数，明确样本、未知时间和 Token 下限。无数据/无匹配与查询失败分开。
- 已访问表单跨分区保留；隐藏区域禁用查询/轮询。告警后台配置变化不重挂载编辑器，维护对账/审计按展开加载；刷新只读取当前视图相关的已激活查询。
- 工件清理改为 Ant Design 上下文确认，提交保留天数冻结，取消不写入，实际范围由服务端再次核验。备份显示“副本检查通过”，不称为完整恢复演练。

## 样式与兼容边界

旧 CSS 保持层内相对优先级并置入 `legacy` 层；旧输入/表格基础选择器显式排除 Ant Design DOM，不导入全局 reset。不生成包裹存量页面的 `.ant-app` 容器，避免其链接重置覆盖旧导航。主题通过 ConfigProvider 管理，新 CSS 只负责工作台布局。

紧凑 Tabs 保证 320px 四个分区可直接点击；中文短按钮关闭自动插空，保留可读标签。JSDOM 的响应式与伪元素 API 仅在测试中适配，不用测试替身推断真实浏览器焦点/尺寸。

下列内容尚未全量迁移：项目/模型/规则等配置表单、任务与问题批量表、补审预算弹窗、存量地址/审计/对账内部控件、应用壳导航。这些模块本轮是兼容回归，不是已经完成 Ant Design 迁移。保留 Radix 与旧组件，待调用方清零并验证后再删除。
