# Ant Design 首批接入与运行监控改造

日期：2026-11-08。关联 PI-20261107-007、PI-20261107-010；其余页面按 PI-20261107-011 规划继续。代码接入和本地验收不代表业务实例已经发布。

## 本批交付

- 锁定 `antd@6.7.0`，应用级中文语言、灰白蓝主题与上下文弹窗由 `frontend/src/app/DesignProvider.tsx` 管理。不引入 ProComponents、Ant Design Pro 或图表库。
- AGENTS.md 与前端规范规定新增/重设计的通用控件统一 Ant Design；业务组件、语义 HTML 和浏览器原生关闭确认保留，复杂状态不同时机械迁入 Form。
- 运行监控拆成“运行与并发 / 性能分析 / 告警与通知 / 维护与审计”，URL 标签、刷新和返回保留定位。默认运行页将并发与槽前置，窄屏先显示并发面板。
- 初审排队/运行读 `execution_jobs`，不再使用有效结论状态冒充执行数；旧 API 缺失显示未知。历史失败与运维风险分开展示，不解析告警文字猜恢复动作。
- 并发保留 1～10 整数校验、冻结版本、409 保留草稿且不重放；并列展示已保存、已应用、执行中和排空，版本未对齐提示等待后续确认。
- 性能采用紧凑分组表、URL 本地筛选、分页和行详情；不合成总体分位数，明确样本、未知时间和 Token 下限。无数据/无匹配与查询失败分开。
- 已访问表单跨分区保留；隐藏区域禁用查询/轮询。告警后台配置变化不重挂载编辑器，维护对账/审计按展开加载；刷新只读取当前视图相关的已激活查询。
- 工件清理改为 Ant Design 上下文确认，提交保留天数冻结，取消不写入，实际范围由服务端再次核验。备份显示“副本检查通过”，不称为完整恢复演练。

## 样式与兼容边界

旧 CSS 保持层内相对优先级并置入 `legacy` 层；旧输入/表格基础选择器显式排除 Ant Design DOM，不导入全局 reset。不生成包裹存量页面的 `.ant-app` 容器，避免其链接重置覆盖旧导航。主题通过 ConfigProvider 管理，新 CSS 只负责工作台布局。

紧凑 Tabs 保证 320px 四个分区可直接点击；中文短按钮关闭自动插空，保留可读标签。JSDOM 的响应式与伪元素 API 仅在测试中适配，不用测试替身推断真实浏览器焦点/尺寸。

下列内容尚未全量迁移：项目/模型/规则等配置表单、任务与问题批量表、补审预算弹窗、存量地址/审计/对账内部控件、应用壳导航。这些模块本轮是兼容回归，不是已经完成 Ant Design 迁移。保留 Radix 与旧组件，待调用方清零并验证后再删除。

## 包体积实测

通过 `git archive HEAD frontend` 在临时目录导出用户确认的提交基线，软链接同一套已安装依赖，分别用同一 Vite 构建。基线与首批产物均输出 `/tmp`；未改动业务 `frontend/dist`。下表使用同一个 Python `gzip.compress` 算法比较，不与不同工具的压缩估计混算。

| 指标 | HEAD 基线 | 首批接入 |
| --- | ---: | ---: |
| 入口 JS 原始字节 | 501521 | 772703 |
| 入口 JS gzip 字节 | 161523 | 255084 |
| 全部 JS 分块原始字节 | 740594 | 1523725 |

入口 gzip 增加约 91.4 KiB，全部 JS 不代表首屏全部下载。较重的性能表/告警/维护按分区懒加载，共用 Table 分块约 328 kB 原始体积。首次未拆分时监控分块约 528 kB，拆分后运行入口约 164 kB；应用主入口约 773 kB 仍存在 Vite 500 kB 提示，未通过提高警告阈值掩盖。默认运行页不提前加载分组表实现。

这些是构建体积，不是实测网络耗时、首屏性能分数或内存收益；全站逐步迁移时继续评估，不承诺组件库没有成本。

## 验证与生效

可执行命令见[前端交互检查](frontend-interaction-checks.md#ant-design-首批与运行监控)。本批验收在临时 SQLite、8791 及隔离产物运行，不使用本机业务库推进测试，不调用真实模型、GitLab 或飞书。最终结果以对应 PI 收尾记录为准，不继承其他历史阶段结论。

基础交互覆盖五种视口、中文主题、焦点、Portal、键盘筛选、URL 回退刷新、十槽排空、草稿切换与后台读取、409、缺失字段、读取失败、清理确认。兼容专项覆盖项目草稿、批量仅作用当前页、部分成功保留选择、权限、幂等、预算确认和通知独立重试。

本批不发布业务实例，不重启 API/Worker/monitor，不迁移数据库或修改真实并发/预算。直接打开业务端口可能仍是旧构建；发布操作与生效核对需另行执行。其他页面重设计和 P0 状态修正仍在全站规划内，未在本批完成。

### 最终本地验收结果

- `npm --prefix frontend run lint`、`cd frontend && npx tsc -b` 均通过。
- `npm --prefix frontend test -- --reporter=dot`：28 个测试文件、136 项通过，无未处理错误。
- 隔离 Vite 构建通过；入口包体积警告保留为已知成本，未覆盖业务产物。
- 上述九个基础/兼容浏览器文件：56 项通过；显式开启合成夹具的 `reviewRecovery.spec.ts`：12 项通过。合计 68 项选定浏览器用例，不代表所有专项或真实外部链路全部验收。
- `git diff --check` 与本次四份主文档的本地链接存在性检查通过。

早期失败均已复验：本机 npm 旧缓存 EACCES 改用临时缓存；依赖就绪前 tsc 缺包不计通过；JSDOM 的匹配媒体替身被测试恢复导致两个用例失败，改用稳定测试 API；旧导航链接重置、窄屏 Tabs 点击、中文短按钮定位已在产品/上下文配置修正；旧复选框对齐断言新增组件库 DOM 分支，修正 v6 选择器后保留几何检查。最后补齐旧基础元素的显式排除，再完整重跑上述 56+12 项通过。告警草稿、费用确认、批量选择等通过的是本轮隔离检查，不是对真实模型、机器重启或部署状态的推断。
