- 第 3 项：新增隔离浏览器服务、组件测试与 Playwright 回归入口。`cd frontend && npm test` 的 3 项组件测试、`npm run test:e2e` 的 4 项浏览器流程、lint/build 通过；手机布局截图确认无横向溢出。浏览器测试发现并修复未配置模型时重审返回 500 的问题，相关后端 6 项测试通过。首次运行浏览器测试前执行 `npx playwright install chromium`。
- 第 4 项：排队取消、运行停止请求、OCR 进程组终止、重启停止恢复、批量重审和 MR 补触发已接入页面。每批最多 100 条，重复目标去重并逐项返回冲突。停止先落库，Worker 在 Git 准备边界与 OCR 命令执行中检查；已发生调用仍可能计费。后端全量 146 项测试、mypy、前端 lint/build 与 4 项浏览器回归通过。

- 第 6 项：独立监控进程检查 Worker、队列、评审、投递、备份及磁盘异常，告警和恢复分别持久化，有限退避且支持人工重发。默认关闭，管理员须选择飞书通道启用；launchd 生成器新增 monitor 清单。后端全量 148 项测试、Ruff、mypy、前端 lint/build 通过。
- 第 7 项：项目可选独立模型、OCR 超时、文件上限和 `--max-tokens-budget`；文件超限在预览后阻止模型调用，预算耗尽继续按部分覆盖显示。仅提取 OCR 摘要中明确的数值用量；模型未返回时显示“未提供”，不估算费用。项目队列在途拒绝修改参数和专属模型。后端全量 150 项测试、Ruff、mypy、前端 lint/build 通过。

- 第 10 项：备份命令新增配对恢复到新目录及保留天数，校验 SQLite 完整性、版本和主密钥文件权限；不会覆盖活跃数据。任务 ID 独立单调分配，删除项目后工件纳入待清理清单，monitor 与管理页在工件锁允许时清理。后端全量 153 项测试、Ruff、mypy、前端 build 通过。
- 第 11 项：项目级 GitLab 行内写回默认关闭；MR diff 版本与新增行位置核对后逐条发布，文件级或不可定位发现标记跳过。发布状态、失败和重试独立于 OCR/飞书，GitLab discussion marker 防响应丢失造成重复写入；可为历史任务手动准备发布。后端全量 156 项测试、Ruff、mypy、前端 lint/build 通过。真实 GitLab 写回仍需测试项目验收。
- 第 12 项：项目级合并前审查默认关闭。已鉴权 MR 更新按提交头版本入 SQLite 队列，Worker 复核 GitLab 项目、状态、头提交与 diff 基准，再以 OCR `--from/--to` 审查完整 MR 差异；提交更新立即将旧版本标记失效，运行中的旧 OCR 尽快停止，完成前再次核对 GitLab 当前版本。合并事件也使预审版本失效。管理页独立展示版本与安全结果，未向飞书或 GitLab 自动写回预审结果。后端全量 161 项测试、Ruff、mypy、前端组件测试、lint/build 通过。真实 GitLab MR 更新及 OCR 范围执行仍需测试项目验收。
- 第 13 项：管理员可先创建账号，再显式启用多人登录；只读用户可查看运行、事件和任务，服务端拒绝写操作及 Webhook Token 明文读取。账号密码使用随机盐 scrypt 摘要，会话只保存令牌摘要并在 12 小时后过期；连续登录失败五次锁定五分钟，停用、降权或重置密码立即撤销旧会话，最后一名管理员不可移除。审计日志记录已认证操作的账号身份，旧记录保留“旧记录”标识。后端全量 164 项测试、Ruff、mypy、前端 lint/build 和 5 项隔离浏览器回归通过。切换账号模式须在受控本机管理入口完成。
